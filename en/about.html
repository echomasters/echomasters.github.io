About the site

This is a minimalist and efficient personal navigation page based on WebStackPage.

This project has been heavily customized from the original version, removing Google Fonts and Google Analytics to achieve zero external dependencies and local resources for lightning-fast loading.

It also introduces a data-driven view (nav-data.js), allowing you to easily manage navigation items by simply editing JSON data, without delving into complex HTML structures.
